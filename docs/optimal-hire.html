Overview

Exploring how a résumé matches a role

A project investigating semantic matching between quantitative-finance candidates and high-frequency or algorithmic-trading roles. The approach uses natural-language processing and Siamese neural networks to represent résumés and job descriptions in a shared embedding space.

Similarity between those representations provides a way to compare profiles with role requirements beyond exact keyword matches. The public application repository includes candidate search and profiles, company profiles, job creation, and an employer dashboard.

Model and application

The matching approach explores shared-weight architectures and distance measures such as cosine similarity and Euclidean distance. The aim is to represent the mathematical and programming competencies behind a résumé and compare them with a role’s requirements.

The application provides candidate and employer workflows around that idea: maintaining a profile, creating a job, and searching for candidates.
