AI-Driven Hiring

Jun 2024 – Dec 2024

Overview

Organization: Candor International School

For OptimalHire, I built an AI recruitment web app using React.js, Python Flask, MySQL, BERT, and a Siamese network to rank job and candidate matches by semantic similarity. To represent resumes and job descriptions, I generated semantic embeddings using Natural Language Processing (NLP) and shared-weight architectures. Using Euclidean distance and cosine similarity, I compare these embeddings to match candidates with roles based on their mathematical and programming competencies.
