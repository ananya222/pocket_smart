Windows application · Accessibility

Braille Validator

English text can contain errors after translation into Braille. Working with Mitra Jyothi, I developed an English-to-Braille validator to flag potential Unified English Braille errors and support the proofreading process.

The work sits within a wider transcription workflow: access to Duxbury transcription software, Kannada OCR through Trestle Labs’ KIBO platform, and PDF preparation using Adobe tools. The public repository includes a Windows application, documentation, examples, and demos.

Testing and next steps +

In initial testing, the validator detected more than 70% of translation errors. It is a proofreading aid, with human review part of the workflow.

The current validator focuses on English Braille. Mathematics and Kannada Braille are future directions, not current features.

Mobile application · Personal finance

PocketSmart

A personal finance app built around everyday money decisions: adding income, recording expenses, and setting aside money for a goal.

The app brings available balance, recent transactions, and savings progress into a dashboard. Separate flows cover expenses and categories, savings goals and allocation, transaction history, and spending insights.

Inside the app +

Onboarding introduces pocket money and a first savings goal. The app then supports repeated actions such as adding an expense, reflecting on a purchase, and allocating money to a goal.

The current repository contains a React Native mobile frontend, Android and iOS projects, and a Firebase backend. It also includes an SMS-import flow, account settings, and supporting documentation.
